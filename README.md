# Employee HR Data Analysis with Pandas

## Project Overview
Real-world style HR data cleaning and analysis using Pandas.

## Objectives
- Clean missing and inconsistent data
- Analyze employee salaries
- Analyze performance
- Analyze departments and cities
- Perform date/time analysis
- Create HR insights

- NumPy
- Jupyter Notebook
